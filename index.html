01 / About

Frameworks people trust before every release.

I've spent the last five years inside enterprise QA teams at Infosys and Tech Mahindra, building the automation that stands between a release candidate and production. Most of that work is Playwright with TypeScript and Selenium WebDriver with Java — Page Object Model frameworks designed to hold up as a codebase and its test suite both grow.

Lately I've been pulling AI into the workflow itself — GitHub Copilot and Playwright MCP for agentic test authoring — because writing test scripts faster still needs to mean writing them right. I led the migration of a full Selenium-Java suite to Playwright at Tech Mahindra, which is where I learned how much of "faster tests" actually comes down to framework architecture, not tooling.
